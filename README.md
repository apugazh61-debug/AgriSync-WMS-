# AgriSync WMS Core Engine v2.0 🌾📦

A state-of-the-art **Agricultural Warehouse Management System (Agri-WMS)** designed for smart storage optimization and real-time resource monitoring.

## 🚀 Version 2.0 Highlights
- **Nature-Themed UI:** Beautiful lush green paddy field interface with premium glassmorphism.
- **Smart Resource Tracking:** Real-time synchronization of agricultural assets.
- **Enhanced Security:** Robust authentication and role-based access control.
- **Platform:** Spring Boot (Backend), React + Vite (Frontend), MongoDB.

## 🛠️ Tech Stack
- **Frontend:** React, Vanilla CSS, Lucide Icons.
- **Backend:** Spring Boot, Spring Security, JWT.
- **Database:** MongoDB.
- **Provider:** Trecenta Technologies.
